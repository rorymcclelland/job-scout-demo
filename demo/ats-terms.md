# ATS term bank

The terms the ATS match (`tools\ats_match.py`, backlog E11) looks for in an advert, each with the other ways adverts and CVs write it. One per line: `- canonical: alias, alias`. Matching ignores case, plurals, hyphens and "&" versus "and". Add a term when an advert uses one the bank lacks; seeded on 16 October 2026. The demo uses this copy.
